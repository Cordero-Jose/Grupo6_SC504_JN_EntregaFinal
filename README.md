# Sistema de Lubricentro - Grupo 6 SC-504

Proyecto final integrador del curso SC-504 Lenguajes de Base de Datos.

## Descripción

El proyecto consiste en el desarrollo de una base de datos para un sistema web de gestión de lubricentro. El sistema permite administrar clientes, vehículos, citas, órdenes de servicio, productos, inventario, facturas y pagos.

## Contenido del repositorio

- `/sql`: contiene el script SQL final del proyecto.
- `/docs`: contiene el documento IEEE del proyecto.
- `/app`: espacio reservado para la aplicación web.

## Tecnologías utilizadas

- Oracle Database
- SQL
- PL/SQL
- GitHub
